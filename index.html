Cybersecurity · Kali Linux

Phishing Awareness Demo

A learning project on Kali Linux using the Zphisher tool, which clones a login page so it looks almost identical to the real one. I built it to show how convincing a fake page can be, and to raise awareness: never enter your details on a link you don't fully trust.

  • Used Zphisher in an isolated lab to see how closely a page can mimic the real site
  • Highlighted the warning signs, above all checking the real URL before signing in
  • Turned the experiment into simple tips for spotting phishing links
  • Kali Linux
  • Zphisher
  • Phishing awareness
  • Linux CLI
